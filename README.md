# 🧭 Travel Stamp

Travel Stamp is an Android travel-journaling application designed to turn journeys into a personal digital travel passport.

Users can plan trips, record memories, complete journeys, and collect unique digital Travel Stamps as a visual record of the places they have explored.

## ✨ Features

- Create and manage journeys
- Track upcoming and completed trips
- Collect digital Travel Stamps
- Personal travel passport collection
- Add moments, notes, and photos
- Expedition timeline
- Search and organize travel records
- Local backup and restore
- Offline-first experience
- Shareable travel memories

## 🛠️ Built With

- Kotlin
- Jetpack Compose
- Material 3
- Room Database
- Coroutines & Flow
- Android Architecture Components

## 📱 Platform

Android

Travel Stamp is currently under active development and is being prepared for a future Google Play release.

## 🔒 Privacy

Travel history and personal memories are designed with a local-first approach. User data remains under the user's control unless a feature explicitly requires otherwise.

**Active Development**
